Fashion Dashboard
📊 Description

Fashion Dashboard est un projet de visualisation et d'analyse de données développé avec Microsoft Power BI.

L'objectif de ce projet est d'analyser les performances d'une activité de mode/fashion à travers différents indicateurs et visualisations interactives.

🎯 Objectifs
Analyser les ventes et les revenus
Identifier les produits les plus performants
Analyser les performances par catégorie
Suivre les principaux indicateurs de performance (KPI)
Faciliter la prise de décision grâce à des visualisations interactives
🛠️ Technologies utilisées
Power BI
Power Query pour le nettoyage et la transformation des données
DAX pour les calculs et indicateurs
Excel / CSV pour les données sources
📈 Dashboard

Le dashboard contient notamment :

💰 Chiffre d'affaires
🛒 Nombre de ventes
📦 Nombre de produits
📊 Moyenne des ventes
🏆 Produits les plus performants
📈 Évolution des ventes
🔎 Filtres interactifs

🚀 Utilisation

Télécharger le fichier .pbix

Explorer les différentes pages et visualisations du dashboard

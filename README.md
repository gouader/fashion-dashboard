# 👗 Fashion Dashboard

## 📊 Description

**Fashion Dashboard** est un projet de visualisation et d'analyse de données développé avec **Microsoft Power BI**.

L'objectif de ce projet est d'analyser les performances d'une activité **Fashion / Retail** à travers des indicateurs clés de performance (KPI), des analyses produits et des visualisations interactives.

Le dashboard permet de transformer des données brutes en **insights utiles pour faciliter la prise de décision**.

---

## 🎯 Objectifs

Ce projet vise à :

* 💰 Analyser le chiffre d'affaires et les ventes
* 🛒 Suivre les performances commerciales
* 📦 Identifier les produits les plus performants
* 🏷️ Analyser les performances par catégorie
* 📊 Suivre les principaux indicateurs de performance
* 📈 Analyser l'évolution des ventes
* 🔎 Permettre une analyse interactive grâce aux filtres
* 💡 Faciliter l'identification des tendances et des performances

---

## 🛠️ Technologies utilisées

* **Microsoft Power BI**
* **Power Query** — nettoyage et transformation des données
* **DAX** — création des mesures et indicateurs
* **Microsoft Excel / CSV** — sources de données
* **Data Modeling** — structuration et relations entre les données

## 🧹 Data Preparation

Les données ont été préparées et transformées avec **Power Query**.

Les principales étapes comprennent :

1. Importation des données
2. Vérification des types de données
3. Nettoyage des données
4. Gestion des valeurs manquantes
5. Suppression des données inutiles
6. Transformation des colonnes
7. Préparation du modèle de données
8. Création des mesures DAX

---

## 🧮 DAX

Des mesures DAX ont été utilisées pour calculer les principaux KPI et indicateurs du dashboard.

Exemples :

```DAX
Total Sales =
SUM(Sales[Sales])
```

```DAX
Average Sales =
AVERAGE(Sales[Sales])
```

Les mesures permettent notamment d'analyser :

* Le chiffre d'affaires
* Le nombre de ventes
* La moyenne des ventes
* Les performances des produits
* Les performances par catégorie
